# Stephanie Ramirez Salas

Construyo productos web rápidos, accesibles y fáciles de mantener.

Landing construida en el **Taller de Git y GitHub**: cada sección se eligió de una plantilla y se guardó con su propio commit.

## Estructura

```
index.html            esqueleto de la página
sections/hero.html    Hero
assets/css/theme.css  tema (colores y fuentes)
assets/css/styles.css estilos compilados
assets/js/site.js     mejoras opcionales
```

Tema: **Papel**. Para publicarla basta servir esta carpeta como sitio estático (GitHub Pages, Vercel, Netlify…).
